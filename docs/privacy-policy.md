## 中文

### 本地数据

- 快捷方式的名称、网址、图标、分组以及布局和语言等设置存储在本机。选择导入 Chrome 书签时，扩展读取本机书签并创建快捷方式。
- 扩展只在你点击工具栏图标或使用快捷键时读取当前标签页的网址和标题，用于预填添加表单。
- 导入的图片、视频和 Wallpaper Engine Scene（含所选的项目元数据）保存在本机并作为新标签页背景使用。
- 手动导出生成包含书签、分组与布局的本地 JSON。开启自动备份并授权下载权限后，扩展将同样的数据保存在 Chrome 下载目录。备份不上传，卸载扩展后文件仍在，可通过系统文件管理器删除。

### 网络请求

- 查找网站图标时，扩展会向 icon.horse、DuckDuckGo 或 Google 发送快捷方式的域名。请求不包含该快捷方式的网页路径、查询参数、标题或页面内容，也不携带 Cookie。图标会缓存在本机。
- 预设图片（含默认背景）从 Unsplash 加载。你设置的网络图片从相应的主机加载。这些服务可能收到 IP 地址等常规连接信息。

### 可选的序言待办

你允许扩展访问 `hls.kskbl.com.cn` 后，待办面板才会连接该网站。浏览器随请求附带现有的序言登录 Cookie。扩展不读取你的密码，也不提取或保存登录 Cookie。扩展读取所选日期的待办，并在你操作时将变更发送给序言网站，其中包括待办标题、备注、日期、时段或完成状态。待办由网站账号保存，扩展不会在本地持久化待办内容。你可以在扩展里断开连接，也可以在序言网站查看或删除账号里的待办。

### 可选的天气

你可以在设置中手动填写城市和 WeatherAPI.com API Key。启用后，扩展把你填写的城市和 Key 通过 HTTPS 发给 WeatherAPI.com 获取天气。Key 和天气缓存保存在本机。扩展不会请求设备定位权限。

### 数据使用与删除

书签和壁纸功能无需账号。扩展不提供书签云同步，不接入广告、分析、遥测或崩溃上报。开发者不接收你的书签集合、布局设置或导入文件，也不出售或出租用户数据。本扩展对从 Google API 获取的数据的使用遵守 Chrome 应用商店用户数据政策，包括「有限使用（Limited Use）」要求。

你可以在扩展里删除快捷方式和分组，或在设置中移除当前 Scene 的本地副本。卸载扩展会清除它在浏览器中的本地存储。

本扩展不面向 13 岁以下儿童，也不会有意收集其个人信息。政策更新时会修改顶部生效日期。

## English

### Local data

- Shortcut names, URLs, icons, groups and settings such as layout and language are stored on your device. When you import Chrome bookmarks, the extension reads your local bookmark tree and creates shortcuts.
- The extension reads the current tab’s URL and title only when you click its toolbar icon or use its keyboard shortcut to prefill the Add form.
- Imported images, videos and Wallpaper Engine Scenes, including any project metadata you select, stay on your device and are used as new tab backgrounds.
- Manual export creates a local JSON backup of bookmarks, groups, and layouts. If you enable automatic backup and grant the downloads permission, the extension saves the same data in Chrome's download folder. Backup files stay on your device after uninstalling and can be removed with your file manager.

### Network requests

- To look up a site icon, the extension sends the shortcut’s domain to icon.horse, DuckDuckGo or Google. This omits the shortcut’s path, query string, title and page content. Icon requests omit cookies. The icons are cached on your device.
- Preset images, including the default background, load from Unsplash. If you specify an online image URL, your browser requests that image from its host. These services may receive ordinary connection information such as your IP address.

### Optional Xuyan Tasks

The Tasks panel connects to `hls.kskbl.com.cn` only after you grant site access. The browser attaches your existing Xuyan session cookie to these requests. The extension does not read your password or extract or save the session cookie. It reads tasks for the selected date and sends changes you request to Xuyan, including task titles, notes, dates, times or completion status. Tasks are stored in your website account. The extension does not persist task contents locally. You can disconnect in the extension and view or delete tasks on the Xuyan website.

### Optional weather

You can enter a city and your WeatherAPI.com API key in Settings. When enabled, the extension sends that city and key over HTTPS to WeatherAPI.com to retrieve weather. The key and cached weather are stored locally. The extension does not request access to your device location.

### Data use and deletion

Bookmark and wallpaper features require no account. The extension has no bookmark cloud sync, ads, analytics, telemetry or crash reporting. The developer does not receive your bookmark collection, layout settings or imported files, or sell or rent user data. The extension’s use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

You can delete shortcuts and groups in the extension or remove the local copy of the current Scene in Settings. Uninstalling the extension removes its local browser storage.

The extension is not directed to children under 13 and does not knowingly collect their personal information. We update the effective date above when this policy changes.
