把你的 Chrome 新标签页换成自己的分组书签和壁纸。

功能

• 分组书签 — 新建分组,起名、配图标、挑颜色,然后在分组之间拖动网址。
• 两种布局 — 分组卡片布局适合浏览,底部 dock 布局适合把快捷方式收起来。
• 壁纸 — 纯色、精选图片、你自己的图片,或一段安静播放的本地视频。
• 快速添加 — 在任意页面按 Ctrl+Y(mac 为 Cmd+Y),弹窗里网址已经填好。
• 批量操作 — 一次选中多个快捷方式,批量移动、复制或删除。
• 浅色与深色主题,跟随系统或手动切换。
• 中文与英文界面。

使用方法

1. 安装后打开新标签页,默认页已被替换。
2. 点分组里的加号,或在任意页面按 Ctrl+Y 添加当前网站。
3. 拖动快捷方式或分组调整顺序;右上角齿轮里可以改布局、壁纸和语言。
4. 在「导入导出」里备份数据,或一键导入 Chrome 里已有的书签。

隐私

没有账号、不用登录、没有云同步,也没有我们自己的服务器。快捷方式、分组、设置和壁纸都只存在你的电脑上。扩展唯一的外部请求是去公共 favicon 服务取网站图标,只带域名。无广告、无追踪、无统计。

权限

• 「读取和更改您的书签」(bookmarks)只在你点击「从 Chrome 书签导入」时使用,读取已有书签并加进新标签页。
• 「读取您的浏览记录」(当前标签页访问)只在点击扩展图标时授予,用于预填当前网页的地址和标题。
• 网站访问权限仅限四个 favicon 服务,只用于显示网站图标。
