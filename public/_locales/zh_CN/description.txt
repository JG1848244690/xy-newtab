Speed Dial 替换你的 Chrome 新标签页。把默认的"快捷访问"页换成干净、迅速、可定制的书签起始页。由 xy 为希望夺回新标签页的人打造:只做分组书签和壁纸两件事,无广告、无追踪、无杂物。

一键把当前页面加到新标签页。预设全局快捷键 Ctrl + Y(Windows)或 Command + Y(Mac),popup 直接打开到"快捷添加":当前网址已自动填好,你只需输入名称,可选一个分组,回车保存。无需切换上下文、无需复制粘贴。在 popup 里按 Ctrl + 1 到 Ctrl + 5,前五个匹配的快捷方式直接打开,常用网站从 Chrome 任何位置都一键直达。

按你自己的方式整理。新建分组,给它起名、配图标、挑颜色,然后把快捷方式拖进拖出。可以整组收起,拖拽调整顺序,也可以一次选中多个快捷方式批量移动、复制或删除。内置两种布局:适合浏览的分组卡片布局,以及把快捷方式收在底部的 dock 布局。

让新标签页变成你的。纯色、精选壁纸、自己的图片,甚至一段本地视频,都可以安静地铺在快捷方式后面。尺寸和透明度可调,任何背景都能保证可读。浅色 / 深色主题跟随系统或手动切换。界面支持中文与英文,从 13 寸笔记本到超宽屏都排得开。

把书签带走。一键从 Chrome 书签栏导入,或导出 JSON 文件备份,换台机器再还原。想让快捷方式跨设备,登录 Google 账号后可使用可选的云同步:本地有改动会标记出来等你上传,下载则会覆盖本机数据。同步完全可选、手动触发,你不按上传,数据就只在你本机。

默认隐私优先。书签、分组、设置、壁纸全部保存在本地,使用扩展无需注册账号。无广告、无追踪、无统计指纹,不出售、不向第三方共享任何数据。云同步只上传快捷方式与分组,且只在你登录并点击上传之后发生。

为真实使用设计。拥有上百书签的效率党,获得带分组、拖拽、批量操作的真正 Speed Dial。追求干净的极简主义者,获得只留必要功能的新标签页。受够了新标签页塞满返利链接和会员升级的人,获得一个聚焦的替代品,装上即可用,无需配置。

由 xy 打造。这个扩展最初只是我自己每天用的 Speed Dial。它保持小而专注:做好一件事,新标签页,就该是这样。
